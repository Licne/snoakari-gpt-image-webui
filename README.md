# snoakari-gpt-image-webui

零依赖的本地 WebUI：浏览器里调用任意 NewAPI 中转站的 gpt-image / nano-banana / gemini 等图像模型，文生图、改图、多图融合。纯 Python 标准库实现，单文件 app.py，Windows 双击即用，支持跨平台运行。

## 怎么启动

双击本文件夹里的 **`启动WebUI.bat`**，浏览器会自动打开
http://127.0.0.1:8787 即可使用（若未自动弹出，手动访问该地址）。

关闭：直接关掉那个黑色命令行窗口，或按 Ctrl+C。

> 前提：电脑已安装 Python 3.8+。无需安装任何第三方库。

## 首次配置（必看）

1. 复制 `config.example.json` 为 `config.json`（Windows：复制粘贴后重命名）
2. 编辑 `config.json`，填入你的中转站地址与 API 密钥：

```json
{ "api_key": "sk-你的密钥", "base_url": "https://你的中转站地址", "model": "gpt-image-1", "proxy": "" }
```

3. 双击 `启动WebUI.bat` 即可。之后也可在页面右上角 ⚙ 里随时改配置、管理多组中转站。

> `config.json` 含明文密钥，已在 `.gitignore` 中排除，不会被提交到仓库。

## 功能

- **文生图** / **改图·多图融合**（拖拽上传 1~16 张图，支持 PNG 蒙版局部重绘）
- 图形化参数：模型 / 尺寸（auto·预设·自定义 WxH）/ 张数 1~10 /
  画质（low~max 六档，xhigh/max 仅 2.5+ 系列）/ 背景（透明底）/ 输出格式 / 压缩率 / 审核级别
- 参数浏览器本地记忆，下次打开自动恢复
- 右上角「⚙ 设置」：改中转站地址、默认模型、API 密钥（打码显示，留空不改）
- 结果区大图展示，卡片标注实际像素尺寸与体积；历史记录保存在 `outputs/`，页面内浏览、下载、点击放大
- 「设置」里可配置出站网络代理（http/https），默认直连
- 隐私遮罩：「本次结果」标题右侧开关。开启后所有预览图自动模糊遮挡；单击单张图切换遮挡/显示，双击放大查看；开关状态记忆
- 引用：每张图片卡片的「引用」可把该图直接添加到改图输入列表（自动切到改图模式），用于再编辑 / 多图融合
- 本地查看：卡片「本地查看」会在资源管理器中定位到该图片文件（仅 Windows）
- 中止请求：生成过程中再次点击「生成」按钮（此时显示「中止生成」）即可中止本次请求；后端也会尽力掐断上游请求（上游静默期最长等到回传开始时中止）
- 收藏：图片卡片可点「收藏」标记资产（名字前 ★），历史区勾选「只看收藏」进入收藏夹，逐张「引用」加入输入；收藏名单存于 favorites.json
- 重命名：卡片点「重命名」直接改 outputs/ 里的文件名（需带图片扩展名；收藏标记自动跟随；禁止重名与带路径的名字）
- 中转站分组：⚙ 设置里可管理多组中转站（每组独立地址/密钥/代理/模型列表），支持「从接口拉取模型列表」；页顶下拉一键切换，切换后模型列表随组变化；分组写入 config.json
- 模型系列参数适配：gpt-image 系列支持全部参数；nano-banana / gemini / grok 等系列仅支持尺寸、张数等基础参数，选中时画质/背景/格式/审核自动隐藏，请求时也不会携带（避免上游 400）

## 参数速查

| 参数 | 可选值 | 说明 |
|---|---|---|
| 模型 | 由当前分组/设置里的模型列表决定（示例默认列表：gpt-image 系 / nano-banana / banana-pro / banana2 / gemini 图像预览 / grok-imagine 共 30 个） | 可在 ⚙ 设置里分组维护并「从接口拉取模型列表」；非 gpt-image 系为不同厂牌图像模型，走同一接口 |
| 尺寸 | auto / 1024x1024 / 1024x1536 / 1536x1024 / 2048x1152（2K）/ 3840x2160（4K UHD）/ 自定义 | 自定义需：16 的倍数、宽高比 1:3~3:1；最长边与总像素不限；所有模型（含 -2k/-4k）均可自定义，能否生效由上游决定 |
| 画质 | low / medium / high / auto / xhigh / max | low 省钱提速（实测 423 token vs 默认 1650~3300） |
| 背景 | auto / transparent / opaque | 仅文生图；透明底需 png/webp |
| 格式 | png / jpeg / webp | 中转站实测可能无视此参数仍返回 PNG，程序按真实格式命名 |
| 审核 | auto / low | low = 更宽松 |

## 中转站实测行为（重要）

- `quality` 参数真实生效：low 档输出 token 仅约 423（默认 1650~3300）
- `output_format` 会被上游忽略：请求 jpeg 实际返回 PNG，程序按魔数嗅探自动命名扩展名
- 自定义尺寸部分生效：请求 2048x1152 实际返回 1672x941（宽高比保留）
- 中转站对非法参数值不做可靠校验，本地校验（16 倍数、比例、透明底+jpeg 冲突等）已在程序内实现

## 计费提示

## 常见问题

- **双击 bat 闪退**：在文件夹地址栏输入 `cmd` 回车，再执行 `python app.py` 看具体报错
- **端口被占用**：编辑 `启动WebUI.bat`，把 `python app.py` 改成 `python app.py --port 9000`
- **需要走代理**：右上角「⚙ 设置」→ 网络代理，填 `http://127.0.0.1:端口`（暂不支持 socks）；留空即直连
- **改图无反应**：改图必须至少上传一张输入图片
